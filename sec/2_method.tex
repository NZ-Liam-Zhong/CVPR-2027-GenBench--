\subsection{Problem Definition and Benchmark Units}
\label{sec:gb_problem}
Let $v$ denote a source video and let $s$ denote a reconstructed scene. A task instance $\tau$ specifies an initial-state distribution, a language goal, a success predicate, and a termination condition. An embodiment configuration $e$ specifies the robot, end effector, sensors, placement, and controller. An episode evaluates a policy system $\pi$ on $(\tau,e)$ with a recorded initialization seed.

For a declared task distribution $\mathcal{D}$, the target quantity is
\begin{equation}
S(\pi,e;\mathcal{D})=\mathbb{E}_{\tau\sim\mathcal{D}}\!\left[P(\mathrm{success}\mid\pi,e,\tau)\right].
\end{equation}
This quantity is distribution-dependent; convergence on the benchmark does not imply universal real-world generalization. Multiple tasks from one scene and multiple embodiments tested on one task do not constitute independent source scenes.

\subsection{Embodiment and Policy Interfaces}
\label{sec:gb_interfaces}
Expose observations and actions through documented adapters. Log camera configurations, state inputs, action frames and units, control frequency, action chunk length, controller parameters, and robot limits. Report privileged state access, planning tools, prompts, memory, and retry logic for agentic systems. The unit of comparison is the full deployed execution system, not an unspecified model name.

An explicit compatibility matrix separates unsupported configurations from supported configurations that fail. Compare policies on common supported cells. For embodiment selection, separately report task reachability and the cost of infeasibility; do not silently drop unreachable tasks from a deployment-level score.
