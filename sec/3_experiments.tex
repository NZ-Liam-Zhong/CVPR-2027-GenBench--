\section{Experiments}
\label{sec:Experiments}
This section will summarize the experiments we ran on out scenes, primarily the 50 scene benchmark. We will also discuss methods for increasing scene throughput with Issac Lab.

The full GenBench-$\infty$ library contains 1,000 scenes, but benchmarking can be done using a subset of these scenes. Benchmarking can also be used to compare different frontier models, different agentic robotics harnesses, or compare different embodiments. We ran a 50 scene benchmark to compare GPT-6-Astra, Gemini Argon 4, Claude Fable 5.1, and Dream-1. Astra, Argon, and Fable were evaluated on 3 embodiments: a Franka Panda Arm, a  Galaxea R1, and a  Galaxea R1 pro. The Dream-1 API was evaluated on a dual YAM arm.
